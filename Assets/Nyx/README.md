# Nyx - Setor de manutencao interativo

Abra o projeto no Unity 6000.7.0a4. A cena Manutencao_Interativa abre automaticamente e enquadra o inicio da fase. Se precisar seleciona-la manualmente: Assets/Nyx/Scenes/Manutencao_Interativa.unity.

## Controles
- A/D ou setas: andar. Segure Espaco para saltar mais alto; solte para um salto menor.
- Mire na parede marcada ou em uma caixa solida. Clique esquerdo cria o portal roxo; clique direito cria o verde.
- E: pegar a celula (ela fica na mao), instalar no terminal ou soltar.
- R: reiniciar.

## Fase
Empurre as caixas, conecte portais em pontos diferentes das paredes e atravesse o vao eletrificado. Leve a celula ao terminal para destrancar a saida. Caixas tem colisores arredondados e fisica de massa, gravidade e atrito. O tutorial aparece junto dos elementos.

Manutencao.unity e Manutencao_24.unity preservam as versoes anteriores. Os sprites fornecidos pelo usuario ficam em Assets/Nyx/Art/Claude. Os arquivos de origem em Downloads/Nyx nao foram alterados.
